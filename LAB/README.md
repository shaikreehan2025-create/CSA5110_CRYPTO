# Cryptography and Network Security Lab (CSA5110)

This repository contains standard C implementations for classical cryptography ciphers and cryptanalysis exercises designed to compile and run seamlessly on standard C compilers (GCC, Clang, OnlineGDB, etc.).

## Programs Included:
1. `01_caesar_cipher.c` - Caesar Cipher (Shift Cipher)
2. `02_monoalphabetic_cipher.c` - Monoalphabetic Substitution Cipher
3. `03_playfair_cipher.c` - Playfair Cipher (5x5 Matrix)
4. `04_vigenere_cipher.c` - Polyalphabetic Substitution Cipher (Vigenère)
5. `05_affine_cipher.c` - Generalization of Caesar Cipher (Affine Cipher) & Key Analysis
6. `06_break_affine_cipher.c` - Cryptanalysis / Breaking of Affine Cipher
7. `07_gold_bug_cipher.c` - Frequency Analysis & Decryption of Poe's "The Gold-Bug" Cipher
8. `08_keyword_monoalphabetic.c` - Keyword-Generated Monoalphabetic Cipher
9. `09_pt109_playfair_decrypt.c` - Decryption of PT-109 Playfair Code Message
10. `10_playfair_custom_matrix.c` - Playfair Cipher with Given Custom Matrix
